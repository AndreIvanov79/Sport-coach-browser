# Данные и хранение (версия 0.2)

Встроенной отправки пользовательских видео, кадров, точек, отчётов и настроек нет. Нет аналитики, рекламных SDK, серверного API и CDN в исполняемой сборке. Расширения не запрашивают разрешений (`permissions` пуст).

## Что получает приложение

- Выбранный пользователем файл через файловый диалог или перетаскивание.
- Камеру — только после нажатия «Камера» и разрешения браузера. Микрофон не запрашивается (`audio: false`).
- В памяти: исходный File/Blob, текущий кадр, координаты всех найденных людей, их цветовые подписи одежды и текущий отчёт.

Цветовая подпись — средний цвет торса и бёдер каждого найденного человека (6 чисел), снятый с уменьшенной до 256 px копии кадра. Она нужна только для того, чтобы не перепутать спортсмена с партнёром или тренером, и не сохраняется ни в истории, ни в экспорте JSON.

Камера освобождается при остановке, закрытии режима «Камера» или уходе со страницы. Worker с моделью завершается по окончании или отмене обработки.

## Режим «Камера»

- Анализ идёт по кадрам с камеры в реальном времени, в том же Worker.
- Если включено «Записывать видео (для просмотра скелета)», MediaRecorder пишет видео в память. Запись нужна для просмотра с наложением и повторного анализа; в IndexedDB и кеш она не попадает и исчезает при новой записи или закрытии страницы.
- Wake Lock только не даёт экрану погаснуть во время записи.

## Голосовые подсказки

Используются только голоса, которые браузер помечает как локальные (`localService`). Сетевые голоса (например, «Google …» в Chrome) пропускаются, потому что синтез речи на сервере получил бы произносимый текст. Если локального голоса для выбранного языка нет, приложение один раз сообщает об этом и молчит.

## Что сохраняется

- Кеш PWA: код, CSS, иконки, WASM и модель Lite. Модели Full и Heavy кешируются отдельно при первом выборе, без видео.
- IndexedDB (база v2): только отчёты, которые пользователь явно сохранил. В них есть имя исходного файла, время создания, координаты выбранного спортсмена (упакованные Float32Array), метрики, события и объяснения. Других людей в кадре и цветовые подписи история не хранит.
- localStorage: настройки (язык, упражнение, модель, частота анализа, порог видимости, обратный отсчёт, голос, запись с камеры).
- Выгруженные пользователем JSON/CSV/PDF — обычные файлы вне управления приложением.

После первого сохранения приложение просит браузер о постоянном хранилище (`navigator.storage.persist`). Если браузер отказал, он может сам очистить историю при нехватке места; в окне «О данных и хранении» видно, какой режим действует и сколько места занято.

Видео не копируется в IndexedDB, OPFS или кеш. История разделена по видам спорта. Удаление отчёта удаляет его запись из IndexedDB; скачанные файлы удаляются пользователем отдельно.

## Сеть

Первое открытие PWA загружает файлы приложения с адреса его размещения. Обычный веб-сервер может вести журналы этих запросов. После успешного кеширования анализ и история работают без сети. Расширение содержит все исполняемые файлы и модели внутри установочного пакета.

Content Security Policy ограничивает `connect-src` и `worker-src` собственным origin. Это дополнительное ограничение; автоматический тест (`npm run e2e`) также проверяет, что за время анализа не было ни одного запроса за пределы origin приложения.

Локальная архитектура описывает технический поток данных и сама по себе не является подтверждением соответствия всем правовым требованиям.
