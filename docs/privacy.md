# Данные и хранение

Встроенной отправки пользовательских видео, кадров, точек, отчётов и настроек нет. Нет аналитики, рекламных SDK, серверного API и CDN в исполняемой сборке.

## Что получает приложение

- Выбранный пользователем File через файловый диалог или перетаскивание.
- Камеру только после нажатия соответствующей кнопки и разрешения браузера. Микрофон не запрашивается.
- В памяти: исходный File/Blob, текущий декодированный кадр, координаты и текущий отчёт.

Камера освобождается при остановке, закрытии диалога или уходе со страницы. Worker завершается по окончании или отмене обработки.

## Что сохраняется

- Кеш PWA: код, CSS, иконки, WASM и модель, без видео.
- IndexedDB: только отчёты, которые пользователь явно сохранил. В них есть имя исходного файла, время создания, точки, метрики и объяснения.
- Выгруженные пользователем JSON/CSV/PDF — обычные файлы вне управления приложением.

Видео не копируется в IndexedDB, OPFS или кеш. История разделена по видам спорта. Удаление отчёта удаляет его запись из IndexedDB; скачанные файлы удаляются пользователем отдельно. Браузер может сам очистить кеш и историю.

## Сеть

Первое открытие PWA загружает файлы приложения с адреса его размещения. Обычный веб-сервер может вести журналы этих запросов. После успешного кеширования анализ и история работают без сети. Расширение содержит все исполняемые файлы и модель внутри установочного пакета.

Content Security Policy ограничивает connect-src и worker-src собственным origin. Это дополнительное ограничение; автоматический тест также проверяет отсутствие внешних запросов и запросов загрузки пользовательских данных.

Локальная архитектура описывает технический поток данных и сама по себе не является подтверждением соответствия всем правовым требованиям.
